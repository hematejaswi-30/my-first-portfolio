## ✨ Overview

This repository contains the source code for **Hema Tejaswi's Personal Portfolio Website**. Designed with a premium dark-themed aesthetic, smooth interactive animations, and a responsive bento-grid layout, it highlights full-stack web development projects, technical skills, experience, and educational background.

---

## 🚀 Key Features

- **Interactive Hero Banner**: Features typed role animations and dynamic floating particles (`particles.js`).
- **Bento Grid Skills Section**: Visual grid displaying technical competencies across Frontend, Backend, Programming Languages, and Data Analysis tools.
- **Project Showcase Cards**: Highlighting full-stack applications with descriptions, tech tags, and direct links to GitHub repositories and live demos.
- **Interactive Certificate Modal**: Allows visitors to preview certificates and documents directly on the page.
- **Smooth Navigation & Scroll Progress**: Active section tracking, sticky navbar, mobile menu overlay, and cursor glow effect.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile displays.

---

## 🛠️ Tech Stack

### **Frontend & UI**
- **HTML5 & CSS3**: Custom CSS system with CSS variables, Flexbox, Grid, and keyframe animations.
- **JavaScript (ES6+)**: Custom DOM manipulation, interactive modals, counter animations, and event handling.
- **Design System**: Typography using *Playfair Display*, *Inter*, and *JetBrains Mono* via Google Fonts.
- **Icons**: Font Awesome 6.5.1.
- **Background Effects**: `particles.js` library for animated canvas particle backgrounds.

### **Developer Tools**
- **Version Control**: Git & GitHub
- **Deployment**: GitHub Pages / Static Hosting

## 💻 Getting Started

To run this portfolio locally on your machine:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/hematejaswi-30/my-first-portfolio.git
   ```

2. **Navigate into the Directory**:
   ```bash
   cd my-first-portfolio
   ```

3. **Open in Browser**:
   - Open `index.html` directly in your favorite browser, or use a local dev server (e.g., Live Server extension in VS Code).
